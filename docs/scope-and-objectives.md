# Scope and Objectives

## Project Scope
This project focuses on securing the Entra identity plane through the implementation and validation of selected identity and access management controls.

The repository will document:
- the selected control areas
- the configuration approach for each control
- implementation evidence captured during setup
- validation outcomes showing whether each control worked as expected

## Project Objectives
The objectives of this project are to:
- implement key Entra identity security controls
- document each control in a clear and structured format
- maintain implementation evidence in an organised repository
- test configured controls to confirm expected security behaviour
- present the final work as a professional project artifact

## Control Areas
The core control areas included in this repository are:
- Conditional Access
- Multi-Factor Authentication (MFA)
- Identity Protection
- Privileged Identity Management (PIM)

## Expected Outcome
At the end of the project, the repository should provide a clear record of what was implemented, why it was implemented, what evidence supports it, and whether testing confirmed successful operation.
