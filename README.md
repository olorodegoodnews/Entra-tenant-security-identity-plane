# Entra Tenant Security - Identity Plane

## Project Overview
This repository contains the documentation, implementation notes, and supporting evidence for an Entra identity-plane security assignment.

## Objective
The objective of this project is to implement and validate key security controls within the Entra identity plane and to document the configuration process in a clear, structured, and professional format.

## Scope
This repository covers:
- implementation of selected Entra identity security controls
- documentation of configuration steps
- evidence collected during implementation
- validation of expected security outcomes

## Controls Implemented
- Conditional Access
- Multi-Factor Authentication (MFA)
- Identity Protection
- Privileged Identity Management (PIM)

## Repository Structure
- `docs/` - scope, objectives, and validation summary
- `controls/` - implementation notes for each control
- `evidence/screenshots/` - screenshot evidence of configurations
- `evidence/test-results/` - validation and test evidence

## Success Criteria
This project will be considered successful if:
- the selected controls are configured correctly
- each control is documented clearly
- evidence is collected for key configuration steps
- testing confirms that controls work as expected
- the repository remains organized and easy to review
